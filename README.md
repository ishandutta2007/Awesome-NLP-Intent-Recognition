# Awesome-NLP-Intent-Recognition

## Top NLP Intent Recognition Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Intent Classification, Slot Filling & Conversational Language Understanding*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **NLP Intent Recognition Tools**. These tools classify user utterances into predefined intents, extract entities and slots, and power chatbots, voice assistants, and conversational interfaces — using rule-based, statistical, and transformer-based language models.

**Examples** include Salesforce Einstein Intent API, Google Cloud Dialogflow, AWS Lex, Azure Conversational Language Understanding, Rasa, IBM Watson Assistant, Cohere Classify, Hugging Face Inference, Wit.ai, and OneAI (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom model fine-tuning, and transparent intent classification — ideal for developers, researchers, and organizations building data-sovereign conversational AI.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Einstein Intent API](https://www.salesforce.com/products/einstein/)**  
  AI-powered intent classification service integrated with Salesforce for routing and conversational automation.

- **[Google Cloud Dialogflow](https://cloud.google.com/dialogflow)**  
  Conversational AI platform with intent detection, entity extraction, and multi-channel bot deployment.

- **[AWS Lex](https://aws.amazon.com/lex/)**  
  Fully managed conversational AI service for building chatbots with intent recognition and slot filling.

- **[Azure Conversational Language Understanding](https://azure.microsoft.com/en-us/products/ai-services/conversational-language-understanding)**  
  Microsoft's CLU service for intent classification, entity extraction, and conversational app development.

- **[Rasa](https://rasa.com/)**  
  Open-core conversational AI platform with on-premise deployment, intent recognition, and dialogue management.

- **[IBM Watson Assistant](https://www.ibm.com/products/watson-assistant)**  
  Enterprise conversational AI platform with intent detection, entity extraction, and multi-channel deployment.

- **[Cohere Classify](https://cohere.com/classify)**  
  Few-shot text classification API for intent recognition without extensive training data.

- **[Hugging Face Inference](https://huggingface.co/inference-api)**  
  Hosted inference API for transformer models including intent classification and zero-shot classification.

- **[Wit.ai](https://wit.ai/)**  
  Facebook's free NLP platform for intent recognition, entity extraction, and conversational interface building.

- **[OneAI](https://www.oneai.com/)**  
  Language AI platform with intent detection, summarization, and custom skill creation via API.

## Open-Source GitHub Projects

- **[Rasa Open Source](https://github.com/RasaHQ/rasa)**  
  Leading open-source conversational AI framework with intent classification, entity extraction, dialogue management, and custom NLU pipelines. Apache 2.0 licensed.

- **[spaCy](https://github.com/explosion/spaCy)**  
  Industrial-strength NLP library with text classification, named entity recognition, and custom pipeline components for intent detection. MIT licensed.

- **[Hugging Face Transformers](https://github.com/huggingface/transformers)**  
  State-of-the-art transformer models for text classification, zero-shot classification, and intent recognition with fine-tuning support. Apache 2.0 licensed.

- **[Snorkel](https://github.com/snorkel-team/snorkel)**  
  Programmatic labeling and weak supervision framework for training intent classifiers with limited labeled data. Apache 2.0 licensed.

- **[Flair](https://github.com/flairNLP/flair)**  
  Simple framework for state-of-the-art NLP with text classification, NER, and contextual embeddings. MIT licensed.

- **[AllenNLP](https://github.com/allenai/allennlp)**  
  Research library for deep learning NLP with text classification, semantic parsing, and intent detection models. Apache 2.0 licensed.

- **[Spark NLP](https://github.com/JohnSnowLabs/spark-nlp)**  
  Production-grade NLP library for Apache Spark with text classification, NER, and intent recognition at scale. Apache 2.0 licensed.

- **[Stanza](https://github.com/stanfordnlp/stanza)**  
  Stanford NLP library with tokenization, NER, and text classification for 70+ languages. Apache 2.0 licensed.

- **[fastText](https://github.com/facebookresearch/fastText)**  
  Facebook's library for efficient text classification and word embeddings, ideal for intent classification. MIT licensed.

- **[TextBlob](https://github.com/sloria/TextBlob)**  
  Simple Python library for NLP with sentiment analysis, classification, and noun phrase extraction. MIT licensed.

- **[NLTK](https://github.com/nltk/nltk)**  
  Comprehensive NLP toolkit with classification, tokenization, and parsing for building custom intent recognizers. Apache 2.0 licensed.

- **[Gensim](https://github.com/piskvorky/gensim)**  
  Topic modeling and document similarity library useful for intent clustering and classification. LGPL licensed.

- **[Botpress](https://github.com/botpress/botpress)**  
  Open-source chatbot platform with NLU engine, intent recognition, and multi-channel deployment. MIT licensed.

- **[ChatterBot](https://github.com/gunthercox/ChatterBot)**  
  Machine learning-based conversational dialog engine with intent matching and response generation. BSD licensed.

- **[DeepPavlov](https://github.com/deeppavlov/DeepPavlov)**  
  Open-source conversational AI library with intent classification, NER, and slot filling. Apache 2.0 licensed.

- **[CLIP](https://github.com/openai/CLIP)**  
  OpenAI's model for zero-shot classification adaptable for intent recognition across modalities. MIT licensed.

- **[SetFit](https://github.com/huggingface/setfit)**  
  Efficient few-shot text classification using sentence transformers, ideal for intent recognition with minimal data. Apache 2.0 licensed.

- **[Label Studio](https://github.com/HumanSignal/label-studio)**  
  Open-source data labeling platform for creating intent training datasets with ML-assisted annotation. Apache 2.0 licensed.

- **[Argilla](https://github.com/argilla-io/argilla)**  
  Open-source data curation platform for NLP with intent labeling, active learning, and model evaluation. Apache 2.0 licensed.

- **[PaddleNLP](https://github.com/PaddlePaddle/PaddleNLP)**  
  PaddlePaddle's NLP library with taskflow for intent classification, NER, and text matching. Apache 2.0 licensed.

- **[MindNLP](https://github.com/mindspore-lab/mindnlp)**  
  MindSpore-based NLP library with text classification and intent recognition models. Apache 2.0 licensed.

- **[BERT](https://github.com/google-research/bert)**  
  Google's transformer model for fine-tuning intent classification and question answering. Apache 2.0 licensed.

- **[Sentence Transformers](https://github.com/UKPLab/sentence-transformers)**  
  Framework for sentence embeddings useful for intent clustering and similarity matching. Apache 2.0 licensed.

### Additional Strong Open-Source Options

- **[NVIDIA NeMo](https://github.com/NVIDIA/NeMo)** — Toolkit for conversational AI with intent recognition and slot filling models.
- **[OpenNLP](https://github.com/apache/opennlp)** — Apache's machine learning toolkit for NLP with document classification.
- **[Mallet](https://github.com/mimno/Mallet)** — Java toolkit for statistical NLP with topic modeling and text classification.
- **[CoreNLP](https://github.com/stanfordnlp/CoreNLP)** — Stanford's suite for NLP with NER, parsing, and classification.
- **[Moses](https://github.com/moses-smt/mosesdecoder)** — Statistical machine translation toolkit with text classification components.
- **Vector Databases** (Qdrant, Weaviate, Milvus, Chroma) for semantic intent matching.
- **Model Serving** (TorchServe, TF Serving, ONNX Runtime) for deploying intent recognition models.

**Frameworks for building custom systems**: Combine **Rasa** for dialogue management, **Hugging Face Transformers** for model fine-tuning, **SetFit** for few-shot intent classification, **Label Studio** for data annotation, and **Qdrant** for semantic matching to build a complete self-hosted intent recognition stack.
